# Ndzana Teddy Portfolio

A static frontend portfolio site showcasing the work of Ndzana Teddy, a student and frontend developer.

## Overview

This project is a single-page portfolio built with HTML and CSS. It highlights a selection of frontend projects, includes a hero introduction, and provides contact links for email and GitHub.

## Features

- Hero section with introduction and call-to-action buttons
- Selected Work section with project cards and live/code links
- Contact section with email and GitHub profile
- Footer with social links
- Responsive card-based layout and consistent visual hierarchy

## Project Structure

- `index.html` — main portfolio page markup
- `styles.css` — site styling
- `img/` — image assets used for project cards and visuals

## Notable Links

## Usage

Open `index.html` in a browser to view the portfolio.

## Notes

The page uses Google Fonts for typography and an icon font for small interface icons. It is intended as a clean, static portfolio presentation for frontend work.
